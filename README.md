# Personal Portfolio

My personal portfolio website built with vanilla HTML, CSS, and JavaScript.

## Features
- Responsive design with mobile-first approach
- Dark theme with modern glassmorphism elements
- Smooth scroll navigation
- Contact form with validation
- Skills and project showcase sections

## Tech Stack
- HTML5 (semantic markup)
- CSS3 (custom properties, grid, flexbox, animations)
- Vanilla JavaScript (ES6+)

## Setup
```bash
# Clone this repo
git clone https://github.com/vitthaldhawale/FirstRepo.git

# Open in browser
open index.html
```

Or use **Live Server** in VS Code for hot reload.
